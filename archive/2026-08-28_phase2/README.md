# 黄金市场温度与中期配置系统

目标：用免费、可追溯的数据评估黄金市场温度，为支付宝黄金 ETF 联接基金提供以日为单位、持有数周的仓位建议。

## 当前约束

- 初始组合资金：100,000 元
- 当前仓位：现金 100%，黄金 0%
- 首选实盘标的：富国上海金 ETF 联接 C（009505）
- 投资范围：黄金基金与现金；不做空、不使用杠杆
- 决策频率：每日；目标持有期为数周
- 风控：从组合历史最高净值计算；10% 防御、12% 显著降仓、15% 硬停止并复核
- 首次实盘前提：严格的样本外回测优于满仓持有基准，且回撤约束合格

## 建模原则

1. **信息时点真实**：只使用决策时已经公开的数据，宏观指标按发布日期而非统计期入模。
2. **执行真实**：区分 15:00 前后信号、基金净值确认、周末和节假日，不把当日收盘价提前用于交易。
3. **因果克制**：总统讲话、战争、制裁和关税作为事件变量；“操纵市场”等动机推测不直接作为事实特征。
4. **多通道归因**：地缘风险可能推高黄金，也可能通过美元、油价和实际利率产生相反效果。
5. **先回测后实盘**：保留时间序列顺序，采用滚动训练和样本外评价。

## 规划的数据层

- 黄金：伦敦金/国际现货代理、上海金基准价、009505 净值
- 宏观：美元指数、USD/CNY、美国名义与实际利率、通胀预期、联储政策预期
- 风险：VIX、原油、股票风险偏好、地缘政治风险指数
- 供需：央行购金、ETF 持仓/资金流、COMEX 持仓（低频）
- 事件：战争、制裁、关税、总统与美联储讲话、FOMC、CPI、就业等，保存原始来源与发布时间

## 每日报告

报告将包含目标仓位、当日操作、市场温度、置信度、主要驱动、反向风险、组合净值/回撤、数据截止时间和下一观察点。

## 运行消息采集

```powershell
python scripts/collect_news.py
```

原始记录写入 `data/raw/news/news.jsonl`；人工核验后的事件写入 `data/curated/`。原始标题不能直接触发交易。

## 运行行情与宏观采集

```powershell
powershell -ExecutionPolicy Bypass -File scripts/update_market_data.ps1
```

该入口先保存 FRED 原始压缩快照，再更新国际行情与 009505 的全部历史净值，并将完整性摘要写入 `data/quality/market_collection.json`。

> 本项目是研究和决策支持工具，不承诺收益。免费数据可能延迟或修订，报告必须显示数据时点和缺失情况。
