# 长期状态筛选：研发记录

在原有2021—2024选参、2025年至今仅作否决的流程外，增加2017—2020年人民币金价代理状态检验。代理价格为伦敦金×USD/CNY，目的在于覆盖2018回落和2020急涨；它不替代两个产品的正式交易账本。

## 长期稳健候选

| 参数 | 值 |
|---|---:|
| 趋势窗口 | 120日 |
| 波动率目标 | 12% |
| 最高仓位 | 95% |
| 回撤退出 | 10% |
| 冷静期 | 5个观察日 |
| 检查与调仓带 | 月度 / 5% |

| 检验 | 积存金代理 | 建信A |
|---|---:|---:|
| 全期年化 | 11.76% | 12.81% |
| 全期最大回撤 | 10.52% | 11.37% |
| 全期平均仓位 | 44.27% | 44.26% |
| 2017—2020人民币金价代理最大回撤 | 12.60% | 12.60% |

## 压力结果

额外一天延迟、积存金点差加倍加单边0.1%滑点、建信A按1.5%申购费和T+7到账均维持13%内部回撤与65%平均仓位预算。

该版本的近年收益低于V3，故不作为收益优先替代；它是用于衡量长期状态稳健性的候选。
