# 基准1 独立运行包

双击运行.cmd：默认2005年至本地最新完整日；结果写到output。
指定范围：`运行.cmd --start 2012-01-01 --end 2021-12-31`。
配置config.json固定，代码engine.py和run.py自包含；runtime内附Python和依赖库，无需原项目scripts、另一基准文件夹或quant_env。Windows系统字体用于作图。
唯一外部业务输入是用户要求不移动的伦敦金K线：data_source.json记录路径；可用`--data-root`覆盖。不联网、不下单、不更改源数据。
保留结果是此前两基准与全仓的正式对比副本。运行包仅做现货固定策略回测与目标仓位，不冒充基金/积存金实盘执行。
研究与规则见策略与研究思路.md。单边成本0.3%，次根开盘执行。
