# 金银比专题研究

本目录记录2026-09-23至09-24完成的金银比研究。核心结论是：金银比适合解释相对表现和辅助观察风险环境，但现有证据不足以支持它单独预测黄金方向或直接生成买卖信号。

## 建议阅读顺序

1. [综合研究报告](综合研究报告.md)：合并初步研究、多轮验证、100项研究和期限应用后的唯一权威结论。
2. [100项研究台账](hundred/100项研究台账.md)：逐项查看证据、反证和边界。
3. [多因子系数与检验表](hundred/多因子系数与检验表.md)：查看完整统计结果。
4. [未来1、3、6、12个月原始快照](outlook-2026-09-24/期限与区间分析.md)：查看当时行情、公式与来源。

- `hundred/`：100项研究协议、台账、模型、结果与独立复核。
