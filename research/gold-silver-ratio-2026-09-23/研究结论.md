# 金银比与黄金投资：初步研究与交叉验证

研究日期：2026年9月23日。结论适用于研究框架，不构成当日买卖信号。

**白银价格和金银比可以辅助判断黄金所处的市场环境、相对表现和波动风险；本轮证据不足以支持用一个固定金银比，独立决定黄金买卖。** 判断黄金自身收益，需要把共同宏观因素与白银特有的供需因素分开。

本轮检索覆盖长期联动、均值回归、关系随时期变化、领先滞后、波动预测、工业供需和中文机构研究。核对了支持与反对固定关系的代表性证据，并用世界银行历史价格做了独立的初步检验。公开互联网无法被穷尽，本文件不是“所有研究已经验证”的声明。可访问的全文与仅能核对摘要的文献在下表中分别标明。

金银比定义为相同货币、相同重量单位下的黄金价格除以白银价格。例如黄金3000美元/盎司、白银30美元/盎司，金银比就是100。比值高只表示一单位黄金可以兑换更多单位白银；“比过去相对更贵”并不自动等于黄金绝对高估或白银绝对低估。

比值的变化满足精确关系：

`新金银比 / 旧金银比 = (1 + 黄金收益率) / (1 + 白银收益率)`

以下三种情形均能使金银比从100降到80，黄金的方向却完全不同：

| 假设情形 | 黄金收益 | 白银收益 | 比值结果 |
| --- | ---: | ---: | ---: |
| 黄金走弱 | -20% | 0% | 80 |
| 白银补涨 | 0% | +25% | 80 |
| 两者上涨、白银更快 | +20% | +50% | 80 |

这首先排除了一个逻辑错误：即使能正确预测金银比下降，也只确定白银相对黄金表现更好，不能单独确定黄金上涨或下跌。比值上升同理，黄金可能上涨，也可能只是跌得更少。

**影响比值的是两种金属对同一冲击的不同反应，以及它们各自的独有冲击。** 下表是基于需求结构提出的条件性解释，不能把每一行当成已被识别的固定因果系数。[世界黄金协会2026年对比研究](https://www.gold.org/goldhub/research/gold-safe-haven-versus-silver-wildcard)、[CME的相对价值研究](https://www.cmegroup.com/insights/economic-research/2026/the-relative-value-prospects-of-precious-metals-in-2026.html)与[世界白银协会2026年比值报告](https://silverinstitute.org/wp-content/uploads/2026/07/Is-the-Gold-Silver-Ratio-Relevant-Today.pdf)提供了相应机制的依据。

| 主要变化 | 对金银比的可能作用 | 黄金投资者应怎样理解 |
| --- | --- | --- |
| 避险需求增强、经济衰退担忧上升 | 黄金的储备与避险需求相对受益，白银工业需求承压，比值可能上升 | 表示防御性需求较强，不等于黄金必涨；流动性紧张时两者都可能下跌 |
| 工业景气改善、白银用量增长 | 白银相对受益，比值可能下降 | 可能反映周期需求，未必对黄金提供新的上涨信息 |
| 央行购金或黄金特有资金流入 | 主要作用在黄金一侧，比值可能上升 | 高比值可以有结构性原因，不应仅凭历史均值卖金 |
| 白银矿山扰动、可交割库存紧张 | 若主要推高白银，比值可能下降 | 先核实白银市场特有因素，不能推导黄金必然补涨 |
| 白银节约使用、材料替代、回收增加 | 可能减弱白银相对支撑，使比值上升 | 工业装机量增长不等于白银需求必然增长 |
| 贵金属投资热、杠杆与持仓变化 | 白银较小的市场可能放大涨跌，形成比值快速压缩或扩张 | 可提示拥挤或去杠杆风险，方向需要其他信息确认 |
| 实际利率、美元、通胀预期变化 | 常同时影响两者，比值方向取决于相对敏感度 | 不能把“有利于贵金属”机械写成“金银比一定下降” |

最后一行尤其容易被误解。若美元变化让金银按相同比例上涨，比值完全不变。白银协会2026年报告也发现，它所测试的美元、利率、通胀、制造业指标对比值的解释力并不一致。因此，“金银比就是经济景气指标”或“金银比就是美元指标”都过于简化。其报告还提醒，投资需求与可动用金属存量很重要，不能仅用年度矿产量或地壳丰度确定合理比值。

对白银工业需求的判断也需更新。2026年《世界白银调查》报告2025年工业需求下降约3%，并讨论光伏节银与替代的影响。这是对“光伏增长必然持续抬高银价”的直接限制条件，而不是对白银以后必然下跌的证明。[World Silver Survey 2026](https://silverinstitute.org/wp-content/uploads/2026/04/World-Silver-Survey-2026.pdf)

比值本身首先是两项价格共同形成的结果。它可以影响交易者的相对配置、跨品种头寸和风险预算，进而反馈到订单流与波动；但不能仅从比值和价格相关，就证明比值造成了金价变化。金银不能按固定比例自由兑换，跨品种交易也没有强制到期收敛机制，因此所谓“金银套利”通常仍承担价格、波动、资金成本及关系变化的风险。

**代表性研究并未形成“固定均值可以稳定指导黄金择时”的一致结论。**

| 研究与证据类型 | 本轮核对内容 | 对本问题的含义及限制 |
| --- | --- | --- |
| [Escribano与Granger，1998](https://e-archivo.uc3m.es/entities/publication/d967f40a-1789-48f1-97ad-3ace8471d89f)，期刊论文，核对大学文库摘要 | 1971—1990年月度样本，长期关系与1979—1980年泡沫、样本时期有关，也研究了样本外预测问题 | 早期文献已经注意到阶段差异；仅据摘要不评价其具体预测效果 |
| [Ciner，2001](https://citeseerx.ist.psu.edu/document?doi=212d26c9e26fe635889ff293f838b3bb036c9755&repid=rep1&type=pdf)，期刊论文，核对原文首页摘要 | 东京商品交易所金银期货样本中的长期稳定关系在1990年代消失 | 是反对固定关系的证据，但不能外推所有市场和以后时期 |
| [Lucey与Tully，2006](https://brianmlucey.wordpress.com/wp-content/uploads/2011/05/goldsilver_cointegration.pdf)，期刊论文，核对作者提供全文 | 1978—2002年的动态检验认为总体长期关系存在，部分时期较弱 | 支持联动，同时提醒短样本可能得出不同结论 |
| [Schweikert，2018，2017年作者稿](https://karstenschweikert.github.io/qcoint/qcoint_20171121_preprint.pdf)，期刊研究，核对全文 | 金银关系有非线性和状态差异；结论明确提醒这种关系不能直接用于预测，固定系数交易有风险 | “存在联系”不等于“存在可直接交易的预测规则” |
| [Caporale、Fons Palomares与Gil-Alana，2026](https://www.ifo.de/DocDL/cesifo1_wp12559.pdf)，CESifo工作论文，核对全文 | 2010—2025年期货数据在2017年末前后出现变化；全样本稳定关系证据不足，变化后的子样本存在关系 | 支持按市场阶段研究，尚属工作论文；不能把事后发现的变化日期当作事先已知 |
| [白银协会／Precious Metals Insights，2026年7月](https://silverinstitute.org/wp-content/uploads/2026/07/Is-the-Gold-Silver-Ratio-Relevant-Today.pdf)，行业报告，核对全文 | 1970—2026年5月月度数据，主张约59.65的均衡比值，估计偏离减半约需17.3个月；末页又讨论2022年以来央行购金导致长期偏离的可能 | 是均值回归的支持证据，但不是黄金单边收益的样本外盈利证明；正文的条件比新闻稿更完整 |
| [Lyócsa、Todorova与Zhu，2026年7月版](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7170627)，工作论文，核对公开摘要 | 用2009—2025年日内期货数据，从比值异常偏离提取的信息改善后续波动预测 | 支持研究风险管理用途；预测的是波动，不是黄金涨跌，且不能直接替换为“比值高”一个条件 |
| [Bouri与Jalkh，2019](https://www.sciencedirect.com/science/article/pii/S2110701718301513)，期刊论文，核对摘要及公开介绍 | 金银期权隐含波动存在依赖与阶段性领先滞后关系 | 白银的信息可能体现在黄金风险上，不能将隐含波动结论改写成银价领先金价 |
| [中金财富期货《2024年贵金属市场展望》，2023年12月](https://www.ciccwmf.cn/u/cms/zjcfqh/202312/271009148aq8.pdf)，机构展望，核对原文 | 用黄金宏观判断及金银比情景推导白银价格 | 展示机构如何使用比值；研究方向主要是由黄金及比值推白银，不证明银价可以反向准确预测黄金 |

不同结论有几类原因：现货和期货不同，美元和日元等计价不同，日度和月度不同，时期不同，以及模型允许的关系变化不同。行业协会研究还具有服务本行业的目标，应与独立论文及实际预测结果一起看，不能只按机构名气决定可信度。

还有一个数学上的限制：如果论文发现的是 `log(金价)=a+b×log(银价)+误差`，只有在额外条件满足时才能改写为固定比值围绕常数波动。若b不等于1，金银比仍可能随价格水平变化。即便存在均值回归，也需要知道调整由哪种金属完成、速度多快，以及交易成本和资金约束是否允许等待。

**独立数据检验提供了“同期联动明显，简单择时能力不足”的初步证据。**

价格来自[世界银行Pink Sheet月度数据](https://www.worldbank.org/en/research/commodity-markets)。下载版本日期为2026年9月2日，包含1960年1月至2026年8月，共800个月。金银均为美元/金衡盎司的月均价。这里计算的是“金价月均值÷银价月均值”，不是“每日金银比的月均值”，也不是月末比值。

为减少固定货币制度的影响，分析从1972年开始；预测评价的价格终点固定为2025年12月。1972—2025年金银月度对数收益同期相关系数为 **0.716**。银价月度变化与间隔一个月后黄金一个月收益的相关系数，在1972—1999、2000—2012、2013—2025三个信号时期分别约为 **-0.089、-0.085、0.011**。两项资产一起变化的证据，明显不能直接当作银价提前提示黄金方向的证据。

各时期比值的算术均值如下。这些差异说明“高低”的历史参照很重要，单凭均值不同本身并不能在统计上否定长期均值回归。

| 月度样本 | 月数 | 金银比均值 |
| --- | ---: | ---: |
| 1972—1979 | 96 | 33.7 |
| 1980—1989 | 120 | 52.7 |
| 1990—1999 | 120 | 73.6 |
| 2000—2009 | 120 | 61.5 |
| 2010—2019 | 120 | 67.5 |
| 2020—2025 | 72 | 83.2 |

预测检验按时间向前推进，每次只用当时已有的历史数据估计模型，不把尚未发生的收益放进训练集。基准模型使用黄金自己的1个月和12个月历史收益，扩展模型再加入白银1个月收益及金银比的对数。另比较只用金银比的模型与历史平均收益预测。模型形式、时期与期限在第一次查看结果前确定，但本研究不属于正式预注册检验。

由于是月均价格，信号为t月数据，评价目标设置为t+1月均价到t+1+h月均价的收益，留出一个月间隔以减少均价重叠与时间错位造成的假领先关系。h分别取1、3、12个月。该设计评估预测信息，不模拟月末可成交交易。

| 预测收益期限（均在一个月间隔之后） | 可评价预测数 | 扩展模型相对黄金自身模型：均方预测误差变化 | 只用金银比相对历史均值：均方预测误差变化 |
| --- | ---: | ---: | ---: |
| 1个月 | 310 | 增加2.1% | 增加3.4% |
| 3个月 | 308 | 增加4.5% | 增加8.7% |
| 12个月 | 299 | 增加16.0% | 增加18.3% |

预测从2000年1月开始，最后一笔预测的收益结束于2025年12月；期限越长，最后一个可评价信号越早。扩展模型在2000—2012和2013—2025两个信号子时期也没有降低相对黄金自身模型的均方误差。只用金银比预测1个月方向，整体命中率约48.4%，历史平均收益基准约54.5%；这些是描述统计，不是显著性检验。

源文件说明黄金报价口径自2025年6月改变，因此额外把评价价格终点退到2024年12月复查。扩展模型在1、3、12个月期限的误差仍分别增加约1.8%、3.8%、15.8%。该复查只针对口径变化这一已发现问题，没有据此挑选最佳参数。

这组结果不能证明所有银价信息都无用。它没有研究滚动模型、非线性状态、日度成交、异常波动或美元实际利率控制变量；没有交易成本、人民币汇率、基金执行规则或持仓回撤回测；历史修订版本也没有完整追溯，因此属于“伪样本外”的探索性检验。3个月与12个月目标相互重叠，不能当成数百个独立样本做普通显著性推断。现有结果只支持：**暂时没有理由把这两类简单输入直接升级成黄金买卖规则。**

历史情形也显示，同一个比值方向可以伴随不同的黄金表现。以下全部用月均价格计算，不能与盘中最高、最低点混用：

| 观察区间 | 金银比变化 | 黄金变化 | 白银变化 | 含义 |
| --- | ---: | ---: | ---: | --- |
| 2008年3月—10月 | 50.2→77.6 | -16.6% | -46.1% | 比值上升可以只是白银跌得更深 |
| 2011年4月—9月 | 34.7→46.4 | +19.6% | -10.5% | 极低比值之后，黄金仍可上涨 |
| 2020年3月—8月 | 106.8→72.9 | +23.7% | +81.2% | 高比值回落可以由两者同涨、白银更快完成 |
| 2025年4月—12月 | 99.9→69.2 | +33.9% | +93.5% | 同样不能从比值下降推断应该卖出黄金 |

以上是说明逻辑的事后案例，不是独立的交易规则检验。2026年8月的月均报价计算得到比值约67.45，只是有日期的描述数据，不用于生成当前买卖结论。

**用于黄金投资时，建议将金银比放在辅助观察位置，并同时查看价格方向与变化原因。**

| 已观察到的组合 | 值得进一步核查的解释 | 不能直接推出的结论 |
| --- | --- | --- |
| 黄金涨、白银涨得更快、比值降 | 贵金属行情扩散，或白银独有需求／持仓冲击 | 黄金马上见顶或一定继续涨 |
| 黄金涨、白银弱、比值升 | 避险或央行购金主导，也可能有白银需求问题 | 黄金必须回调 |
| 黄金跌、白银跌得更多、比值升 | 流动性压力、工业预期走弱或去杠杆 | 黄金可以立刻抄底 |
| 黄金横盘、白银猛涨、比值降 | 白银短缺、挤仓、资金流或补涨 | 黄金必然跟涨 |

对于人民币计价的积存金或黄金基金，还需注意：若把金银都按同一个汇率换成人民币，汇率在比值中会抵消，但人民币黄金的实际收益仍受汇率影响。近似关系是 `人民币黄金价格 ≈ 美元黄金价格 × 美元兑人民币汇率 ÷ 31.1035 × 本地价格差异`。基金还存在费用、跟踪偏差和执行时点。国内金银报价混用不同单位、市场、税费或时刻，会产生没有经济意义的比值变化。

下一轮最有价值的检验是：在既有黄金模型和执行规则不变的条件下，分别添加金银比水平、变化速度、银价异常波动，检验它们是否在严格的样本外评价中改善回撤、风险预测或净收益。特别应把“减轻风险”与“提高方向预测”分成两个目标。本轮没有修改现有黄金策略。
