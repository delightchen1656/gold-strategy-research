# 金银比、市场情绪与基金持仓：整合研究报告

后续更新：根据本次明确的“仅国际美元市场”范围，已完成[三轮循环研究](cycles/三轮研究报告.md)，补入GVZ、持仓公布延迟、替代工具与2026年压力检验。下文保留此前研究快照；最新判断以三轮报告为准。

研究更新：2026年9月23日。整合本对话提出的相对估值、黄金投资参考、变化速度、市场情绪、资金先后关系及因果关系，并补充第二轮独立数据检验。评价结果终点固定在2025年，未用2026年表现挑选参数。本研究没有生成当日买卖建议。

**目前较有支持的用途是解释金银相对表现、辅助观察风险环境；尚未找到足够稳定的证据，支持单凭比值水平或变化速度预测黄金方向、识别“主力下一步”，或据此改变现有黄金策略。** 新增检验进一步表明：同期联系比较清楚，提前预测的增量很小；部分近期风险预测结果值得继续验证，但不能直接变成操作阈值。

| 本对话的问题 | 整合后的回答 | 证据边界 |
| --- | --- | --- |
| 银价能否为黄金投资作参考？ | 能，尤其用于观察行情是否扩散、相对需求和风险压力 | 同涨同跌不等于银价提前预测黄金 |
| 金银比高低由什么决定？ | 两者对利率、美元、增长及避险冲击的不同反应，以及各自供需和资金因素 | 高低要对照时期，不能预设一个永恒均值 |
| 比值会影响什么？ | 可能进入相对配置、跨品种交易、风险预算，再反馈到订单和波动 | 比值本身不是独立于金银价格的外部冲击 |
| 速度、加速度能否反映情绪？ | 可以描述相对价格变化的方向、急迫程度和异常程度 | 不能仅凭快慢区分恐慌、挤仓、工业需求或央行购金 |
| 比值与“主力决定”谁先？ | 机制允许双向反馈；可观察的周度基金持仓以同期关系更明显 | 报表看到得晚，不等于基金行动得晚 |
| 有没有因果关系？ | 订单和报价会参与价格形成；比值也可能触发规则交易 | 本轮不能识别具体机构决策，也没有识别出稳定的单向因果效应 |

**先把比值、黄金收益和市场情绪分开。**

相同币种、相同重量单位和可比时刻下，金银比为 `R=G/S`。精确关系是 `R新/R旧=(1+黄金收益率)/(1+白银收益率)`；用对数收益表示，则 `ΔlnR=ΔlnG−ΔlnS`。

因此，比值从100降到80，可以是黄金跌20%、白银不动；也可以是黄金不动、白银涨25%；还可以是黄金涨20%、白银涨50%。预测比值方向，只能确定相对表现，不能确定黄金单边方向。比值上升也可能只是白银跌得更多。

| 冲击来源 | 比值可能如何变化 | 应核查的事实 |
| --- | --- | --- |
| 防御需求、衰退担忧 | 黄金相对占优，比值可能上升 | 黄金自身涨跌、股市、VIX、实际利率、流动性 |
| 工业需求改善 | 白银相对受益，比值可能下降 | 工业活动、白银实际用量，而非只看装机或产量标题 |
| 央行购金、黄金独有需求 | 比值可能长期偏高 | 储备需求和黄金资金流是否确有变化 |
| 白银供应、库存或交割压力 | 白银可独立走强，比值下降 | 可交割库存、期限价差、租赁及现货紧张程度 |
| 贵金属行情扩散或去杠杆 | 白银可能放大涨跌，比值快速变化 | 两边的价格、成交、多空组成和融资条件 |
| 美元、实际利率变化 | 两者共同受影响，但比值取决于敏感度之差 | 不能把对贵金属的共同影响直接当作比值方向 |

这些是条件性机制，而非固定交易规则。黄金与白银需求结构的差异可参见[世界黄金协会对比研究](https://www.gold.org/goldhub/research/gold-safe-haven-versus-silver-wildcard)、[CME相对价值研究](https://www.cmegroup.com/insights/economic-research/2026/the-relative-value-prospects-of-precious-metals-in-2026.html)。白银工业需求还受节约用银和替代影响，不能简单等同于新能源等行业的总规模增长，见[《World Silver Survey 2026》](https://silverinstitute.org/wp-content/uploads/2026/04/World-Silver-Survey-2026.pdf)。

**“变化快”需要区分三个量，不能都叫市场恐慌。**

设 `q=lnR`。某个固定观察窗口内的变化为 `q(t)−q(t−h)`；除以天数h才是平均每日速度。比较相邻两个窗口的速度，得到加速度的离散近似。比值日变化的波动则衡量上下摆动幅度，没有固定方向。还可将变化减去历史均值，再除以历史标准差，衡量相对历史的异常程度。

本轮对应使用5日和20日对数变化、相邻5日变化之差、20日比值波动，以及5日变化相对过去252个交易日分布的异常绝对幅度。它们对应不同问题：方向是否偏向黄金、这种偏向是否加快、市场是否剧烈摆动、当前变化是否罕见。不同资产同步大跌时，比值甚至可以几乎不动，因此不能把比值平静等同于黄金低风险。

| 观察到的组合 | 可以提出的解释 | 仍然无法单独确定 |
| --- | --- | --- |
| 比值快速上升，黄金上涨、白银下跌 | 防御需求增强，或白银受到独有冲击 | 是广泛避险还是白银供需变化 |
| 比值快速上升，两者都跌、白银更弱 | 去杠杆、流动性紧张或增长预期恶化 | 黄金是否已经跌到可买的位置 |
| 比值快速下降，两者都涨、白银更强 | 行情扩散、风险偏好增强或白银拥挤 | 黄金是否见顶，以及趋势能持续多久 |
| 比值快速下降，黄金下跌而白银稳定 | 黄金独有压力 | 不能自动称为风险偏好改善 |

这部分的独立描述统计采用每周最后交易日对应的过去5日变化，完整观察期为2007年5月11日至2025年11月28日，共969个周观察。金银相对价格代理与标普500收益的同期相关约 **−0.370**，与VIX对数变化的同期相关约 **+0.297**。方向符合“比值走高常伴随风险偏好转弱”的解释，但远非一一对应，更不是情绪的直接测量。VIX是美股隐含波动指标，不是黄金隐含波动。

另外，比值与白银收益的负相关有数学成分：`q=g−s` 本身含有负的白银项。不能把这个相关性全部解释成资金行为。宏观冲击、白银较大的波动和交易行为可能同时存在。

**“主力”需要变成可观察的具体对象，才能检验先后关系。**

本轮把资金对象限定为CFTC分项期货报告中的 Managed Money，分别观察COMEX标准黄金和白银合约，排除微型合约，也不混合期货与期权口径。它并不包括所有机构、央行、场外交易和ETF投资者，报告也不披露每位交易者的决策理由。[CFTC报告及分类说明](https://www.cftc.gov/MarketReports/CommitmentsofTraders/index.htm)

持仓指标为 `(基金多头−基金空头)/总未平仓量`，同时保留多头、空头与合约数。比率变化会受到分母变化影响；净多减少也可能来自平多、开空或两者同时发生，不能直接解释成某个金额的资金流出。总未平仓量增加同时对应多空双方，不能单看增仓就认定净买入。

可以提出的反馈机制是：消息、供需和流动性变化影响交易者决策、报价与订单，继而共同形成两种价格和比值；新的比值又可能进入其他交易者的配比、趋势或风险规则。报价也可能先反映对未来订单的预期。于是，同一过程中既可能有“资金行动后比值变化”，也可能有“比值变化后另一类资金调整”。这是一种机制解释，本轮没有观察到实际指令和决策时刻，不能据此认定固定顺序。

COT通常统计周二持仓，周五美国东部时间15:30发布，假日及特殊情形会延后。CFTC说明没有完整历史公布日期清单。因此，本轮所有持仓检验均按**报告截至日**做事后行为分析，不能作为当时公众已经知道这些持仓的交易回测。[CFTC公布时间说明](https://www.cftc.gov/MarketReports/CommitmentsofTraders/index.htm)

从识别强度看，相关性只能说明共同变化；先后关系还可能来自共同信息反应速度不同；格兰杰类预测只说明在给定模型下增加信息有无帮助；要推断实际因果，还需要可信的外部冲击、细颗粒订单数据和识别设计。本轮做的是增量预测比较，没有把它包装为因果检验。

**新增的数据检验：关联明确，稳定预测增量尚弱。**

第一轮使用世界银行美元/金衡盎司月均价；第二轮新增2006—2025年的4,951个共同日线观察，以及金银各1,021期CFTC持仓。数据、原始来源链接、下载时间、文件校验值及逐期预测均已保留。

第二轮日线采用Yahoo提供的GLD与SLV拆股调整收盘价。二者都是贵金属信托在NYSE Arca的交易价格；GLD/SLV的价格比并非现货金银比，管理费、跟踪误差、每份金属数量和溢折价都会影响它。本轮只将其作为相对变化代理，不对其水平使用60或80一类阈值。[GLD发行方](https://www.spdrgoldshares.com/usa/)、[SLV发行方](https://www.ishares.com/us/products/239855/ishares-silver-trust-fund)

选择这一代理是因免费现货长历史接口受到限制：Stooq返回验证网页，DBnomics旧LBMA接口返回404，Westmetall白银为欧元/公斤经销商报价，不能与美元黄金定盘价直接拼接。上述失败记录保留，没有把网页误当数据。作为交叉核对，剔除首个不完整月份后，ETF代理与世界银行真实比值的月度对数变化相关为 **0.9946**，变化差值的均方根约 **0.519个百分点**。这支持它作为低频相对变化的近似，但不能证明日内行为或极端溢价时仍然一致。

第一轮的黄金收益检验保留：以黄金自身1个月和12个月收益为基准，加入白银1个月收益及金银比对数，向前预测一个月间隔后的黄金收益。2000年开始逐月评价，终点为2025年12月。

| 预测收益期限 | 加入白银与比值后，均方误差相对变化 |
| --- | ---: |
| 1个月 | +2.1% |
| 3个月 | +4.5% |
| 12个月 | +16.0% |

正数代表更差，不是盈利增加。剔除2025年报价口径变更后的数据，结论方向不变。这属于简单线性模型下的否定性结果，不能证明所有白银信息都无用。原始样本、分期结果及文献矩阵见[第一轮研究](研究结论.md)，基础来源为[世界银行商品市场数据](https://www.worldbank.org/en/research/commodity-markets)。

第二轮将“能否预测黄金风险”单独检验。每周最后一个交易日形成观察值，留出一个完整交易日，再预测之后20个交易日GLD的年化均方根波动之对数。基准先使用黄金自己的过去5、20、60日波动和5、20日收益，再设更强的对照，加入前一交易日的VIX水平、美元指数20日变化及10年实际利率20日变化。

采用至少5年初始历史、逐周扩展训练，禁止尚未结束的目标进入训练。共有708个可评价信号，日期为2012年5月11日至2025年11月28日，收益和波动目标均在2025年内结束。误差是对数波动的预测均方误差，**不是黄金收益、最大回撤或波动水平本身的变化**。

| 新增信息 | 相对黄金自身模型：误差变化 | 相对黄金＋宏观模型：误差变化 | 后者的95%区块重采样区间 |
| --- | ---: | ---: | ---: |
| 比值5/20日变化 | −0.94% | −0.04% | −0.98%～+1.02% |
| 相邻5日变化之差 | +0.05% | +0.05% | −0.02%～+0.13% |
| 比值20日波动 | −1.72% | −0.15% | −0.98%～+0.82% |
| 5日变化的异常绝对幅度 | −0.86% | −0.46% | −1.42%～+0.76% |

全评价期内，四类信息相对两个基准的改善区间均包含零，尚不足以确认稳定增量。加入宏观变量后改善缩小，符合“部分比值信息与共同风险环境重复”的解释，但本检验不是对这种机制的因果证明。

有一个需要保留的积极线索：2019—2025年子时期，“异常绝对幅度”相对黄金＋宏观模型的误差降低 **1.22%**，区块区间约 **−2.43%～−0.18%**；2012—2018年却恶化 **0.44%**。分期虽事先规定，但这里比较了多个特征、目标与时期，区间未作多重检验校正，不能只挑这个结果宣布有效。它更适合成为将来全新样本的验证对象。

次级目标也没有支持直接买卖：四类比值信息相对黄金自身模型，对之后20日黄金收益的误差全部增加约 **0.15%～0.62%**；对下行波动的改变约 **−0.30%～+0.38%**，区间均包含零。下行波动不等于投资组合最大回撤，本轮也没有验证减仓能提高净收益。

统计区间使用13周连续区块、2,000次重采样，以保留部分时间依赖和重叠目标。它只近似描述已生成预测误差的不确定性，没有在每次重采样中重新估计所有模型，也未完整覆盖数据误差及模型选择风险。

**资金与比值的先后：目前主要看到同期联系，弱领先没有通过稳定性检验。**

CFTC样本为2006年6月13日至2025年12月30日，共2,042条金银记录。原始报告中有13个周一和1个周三截至日，按实际日期处理，没有强制改成周二；持仓总量平衡检查通过。以下为相同报告周的价格变化与基金净多比例变化。

| 同期关系 | 相关系数 |
| --- | ---: |
| 黄金价格变化与黄金基金净多比例变化 | +0.513 |
| 白银价格变化与白银基金净多比例变化 | +0.480 |
| 金银相对价格变化与白银基金净多比例变化 | −0.455 |
| 金银相对价格变化与黄金基金净多比例变化 | −0.214 |

比值上升时，黄金基金净多也可能下降：例如两种价格都跌、白银跌得更多。**“比值上升＝主力买金卖银”并不成立。** 把基金变化改为净合约数变化除以上一期未平仓量，同期自身价格关联仍为正，黄金约0.582、白银约0.520，说明结果不完全由持仓比例分母引起；仍然不能确定谁造成谁。

| 当周比值变化与何时的白银基金净多比例变化比较 | 相关系数 |
| --- | ---: |
| 前1个报告周期 | +0.010 |
| 同一报告周期 | −0.455 |
| 后1个报告周期 | −0.146 |
| 后4个报告周期 | +0.078 |

“后4个周期”在此是第四个周期的单期持仓变化，不是未来四周累计变化。该表只是描述性线索：最明显的是同期，下一周关联弱一些，更远处又改变方向。后面的预测检验才使用未来1或4期累计变化。

持仓预测基准包含过去4期自身净多比例变化、当前比例及黄金1/4期收益，新增比值1/4期变化。反向价格预测基准包含黄金和比值1/4期收益，新增两种金属的净多比例及当前变化。所有模型按时间向前训练，不含未来目标，但依然是以截至日为时钟的事后研究。

| 增加的信息与预测对象 | 未来1期误差变化 | 未来4期误差变化 |
| --- | ---: | ---: |
| 加比值信息，预测黄金基金净多比例变化 | +0.25% | −0.17% |
| 加比值信息，预测白银基金净多比例变化 | +0.24% | +0.34% |
| 加持仓信息，预测黄金收益 | +0.60% | +2.18% |
| 加持仓信息，预测比值变化 | −0.13% | +0.63% |

主评价自2012年开始，未来1期与4期分别有730、727次预测。表内少量负值的区块区间包含零；分期结果也不稳定。CFTC分项报告自2009年9月公开，早期数据有回溯分类性质，所以额外剔除2009年9月之前的训练观察，重新累积5年后评价，八组比较的平均误差变化全部为正。[CFTC历史数据说明](https://www.cftc.gov/MarketReports/CommitmentsofTraders/HistoricalCompressed/index.htm)

本轮只能说：**这些周度线性设定没有检出稳定的增量领先信息。** 不能据此断言主力没有价格影响、没有机构能提前行动，或所有极端持仓都没有预测价值。这里没有逐笔交易、交易者身份、场外头寸，也没有穷尽非线性规则。

**与网络研究的对照：差异更多来自问题、样本和方法不同。**

公开互联网无法被穷尽，本研究不是“所有相关研究已经验证”。已覆盖支持和反对长期稳定关系的代表性论文、风险预测论文、持仓预测论文、行业研究及官方数据说明。阅读全文与只核对摘要的材料明确区分。

“长期协整”“均值回归”“情绪相关”“领先预测”“因果影响”“扣费后可交易收益”是不同命题。即使发现 `lnG=a+b×lnS+误差`，也不自动意味着 `G/S` 围绕固定常数波动；还要检验b是否为1及关系是否稳定。不存在把金银按固定比率强制兑换的机制，所谓比值套利也会承担长期偏离和融资风险。

**用于现有黄金投资时，先作为解释与观察变量。**

金银比可以进入观察表，但应连同黄金、白银各自收益一起记录；比值异动再对照股票、VIX、美元、实际利率以及白银独有因素。COT显示时同时标明“持仓截至日”和“实际公布日”，并区分平多与加空。现阶段不能据本轮结果设定“高于80买银卖金”“加速上升立即减仓”或“基金增仓后必涨”。

人民币黄金还有额外一层：相同汇率换算金银时，汇率在比值中抵消；人民币黄金收益却仍受美元兑人民币汇率、本地价差、基金费用与执行时点影响。比值研究不能代替人民币投资产品的实际回测。

继续研究最有价值的顺序已经缩小：先对“异常相对变化能否增加风险信息”做全新样本检验，并取得同口径现货或期货数据及黄金隐含波动；再核对日内论文的完整方法；若要判断资金因果，必须增加订单时间、持仓公开时间及可信的外部冲击识别。只有风险预测稳定改善后，才进入遵守原执行规则的仓位与交易成本检验，不能把预测误差改善直接换算成投资收益。

本轮结论已可复核。对1,023个未来波动窗口逐一独立重算，检查训练标签结束时间，复核COT目标对齐，并重新计算129项误差比较，全部通过。原策略未修改。
