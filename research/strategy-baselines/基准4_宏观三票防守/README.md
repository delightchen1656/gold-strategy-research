# 基准4｜宏观分层增仓

基准4由当前“策略2｜宏观三票防守”复制后独立优化。2026-08-31按“提高收益和仓位，同时控制回撤增速”的目标升级为分层投票版本。原策略2仍保留在基线123中，基准4原版保存为 `baseline_4_v1_original.json`。

## 规则

金价首先必须高于MA200，然后根据三项宏观条件分层持仓：

1. 美元指数60日收益率小于0。
2. 美国10年期实际利率60日变化小于0。
3. VIX 20日涨幅不超过15%。

三票成立时使用 `0.14 / 20日年化波动率`，限制在25%至100%；两票成立时使用上述仓位的40%；不足两票时空仓。信号延迟一个伦敦金定盘日执行，每批至少持有7个交易日。

在最大回撤分别限制为13%和15%的条件下，样本内最大收益分别为100.45%和112.59%。两者均不是长期满仓方案，详见 [DD13/DD15最大收益研究](DD13_DD15最大收益研究.md)。当前基准4尚未被这两套高风险版本覆盖。
