# 基准4从2020年至今回测

数据区间：2020-01-02至2026-08-28。初始资金50,000元，以伦敦金美元定盘价作为标的。

## 结果对比

| 指标 | 基准4｜宏观三票防守 | 伦敦金买入持有 |
|---|---:|---:|
| 期末资金 | 80,172.00元 | 151,326.82元 |
| 累计收益 | 60.34% | 202.65% |
| 年化收益 | 7.35% | 18.11% |

| Calmar | 0.672 | 0.654 |
| Sortino | 1.950 | 1.341 |

| 期末执行仓位 | 0% | 100% |

## 结论

基准4的核心价值是防守而不是追求绝对收益最大化。相对伦敦金买入持有，它少赚142.31个百分点，但把最大回撤从-27.69%降低到-10.94%，减少16.75个百分点。Calmar略高，Sortino明显更高，说明按本样本计算的单位下行风险收益更好。

代价也很明确：平均仓位只有22.21%，约70%的交易日完全空仓，因此会错过长期单边上涨。该策略适合作为低回撤过滤器或防守基准，不适合单独代表收益进攻策略。

## 回测假设

- 信号延迟1个伦敦金定盘日执行。
- 每批新增仓位至少持有7个交易日，按FIFO释放。
- 每次仓位变化计入0.1%摩擦成本。
- 不做空、不使用杠杆。
- 伦敦金买入持有对照未额外计申购或汇兑成本。
- 免费数据截止到2026-08-28；结果不等于未来表现。

机器结果见 `backtest_2020_to_latest.json`，逐日净值与仓位见 `backtest_2020_to_latest.csv`，复现脚本见 `backtest_baseline4.py`。
