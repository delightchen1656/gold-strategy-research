# 基线策略

自2026-09-01起，基线版本3.0冻结以下三项策略：

1. 策略1｜低波趋势控仓
2. 策略2｜宏观分层增仓（DD13）
3. 策略3｜美元弱势控仓

策略2已于2026-09-01由DD13替代原“宏观三票防守”；策略1和策略3不变。三项策略均允许完全空仓，每批申购至少持有7个交易日，信号延迟一个伦敦金定盘日执行。策略参数见 `config/baseline_strategies.json`。

旧版十五日波控仓、十日快波控仓和宏观波动减仓不再作为当前策略123，但历史回测与归档继续保留。
