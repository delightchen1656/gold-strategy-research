# 隐私与发布检查

公开仓库只包含研究代码、公共数据、模型参数和匿名化结果。真实本金、买入成本、持仓市值、份额、盈亏、订单、账户截图及实盘工作簿统一保存在 `private/`，该目录被 Git 忽略。

## 禁止进入公开区的内容

- 个人买入成本、真实仓位、分批持仓和盈亏；
- 账户、订单、支付平台截图和交易流水；
- 本机用户名、绝对路径、访问令牌或私钥；
- 根据个人仓位撰写的操作建议，即使未出现账户号码。

## 上传前检查

```powershell
git status --short
git check-ignore -v private/data/current_portfolio.json
git grep -n -I -E "(当前持仓|实际持仓|买入成本|浮动盈亏|确认份额|订单编号|C:/Users/)"
```

不要使用 `git add -f` 强制加入被忽略文件。如果私密内容曾进入 Git 历史，仅修改当前文件不够，还需要重写历史或重新建立干净仓库。
