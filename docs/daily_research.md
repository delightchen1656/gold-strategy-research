# 每日研究规范

基准1是正式策略与研发比较基准。每日研究只在固定参数下更新数据，并进行一个预先限定的改进或稳健性检查；全部尝试都要记录，并明确区分历史优化、压力测试和样本外验证。

## 运行边界

- 北京时间每天 10:00 使用当时已经公开的数据。
- D 日伦敦 AM 定盘形成的信号，最早映射到 D 日之后首个可交易的中国基金净值日。
- 只研究和模拟，不执行实盘交易；个人持仓与操作计划不得进入公开研究。
- 图表继承 2021 年以来的策略状态，只截取滚动近五年展示，不在窗口起点重新择时。
- 收益图包含模型成本；仓位图展示模拟实际仓位，并另列最新目标仓位。
- 积存金仍是价格代理，不代表任一银行的真实历史报价。

## 每次更新应保存

1. 行情、净值、信号各自的截止日期；
2. 本次唯一的研究问题或压力情景；
3. 基准与情景的分阶段年化收益、最大回撤和平均仓位；
4. 数据来源、验证结果与可复现命令；
5. 是否改变基准，以及不改变时的理由。

只有在相同数据、成本和因果时序下取得可复核证据，才讨论替换 `config/baseline_1.json`。个人本金、成本、份额、盈亏和分批计划统一保存在 `private/`。
