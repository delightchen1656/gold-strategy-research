# 消息与政策数据管线

## 来源等级

- Tier 1：政府、央行、交易所、统计机构等原始发布，只证明事件发生及其内容。
- Tier 2：有署名、有方法或引用专业人士的市场研究，用于提取传导逻辑与机构观点。
- Tier 3：新闻聚合、一般财经媒体和公众讨论，只用于发现线索及测量关注度，必须回溯原始来源。

## “多人认为会影响黄金”的量化

按同一事件的时间窗口聚类，统计独立媒体、独立分析机构和不同署名分析者，而不是简单统计转载篇数。保存看多、看空和混合三类观点，并计算：

- 来源独立性：转载同一稿件只算一个观点
- 专业权重：官方事实不预测方向；专业黄金/宏观研究权重高于无署名评论
- 一致度：最大方向票数 / 有效观点总数
- 关注度异常：相对过去 90 天同类消息量的 z-score
- 新颖度：与过去事件文本及政策类别的差异

共识强不代表预测正确。回测会单独检验“高共识事件”之后 1、5、10、20 日的人民币黄金异常收益，并观察市场是否已提前定价。

## 每条事件的必需字段

首次公开时间、采集时间、时区、原始标题、来源、URL、来源等级、事件类别、事实摘要、涉及主体、传导渠道、观点方向、观点置信度、是否为转载、可交易时点和后续价格反应。
