# 方法与验证规范

## 预测对象

模型不直接预测新闻“好坏”，而是分别预测未来 10、20、30 个交易日的人民币黄金收益及下行风险。最终仓位由预期收益、置信度、波动率和组合回撤共同决定。

## 市场温度

温度范围为 0–100，至少包括：

- 趋势与动量
- 美元与人民币汇率
- 美国实际利率和政策预期
- 地缘政治与政策事件
- 风险偏好和波动率
- 黄金资金流与持仓
- 估值/拥挤和反转风险

温度只是状态摘要，不单独触发买卖；必须同时给出置信度和反向证据。

## 事件研究

每条事件保存首次公开时间、来源、事件类别、涉及主体和原文链接。按事件发生后的 1、5、10、20 个交易日计算黄金异常收益，并控制同期美元、实际利率、油价和市场风险。相似事件只使用当时之前已经发生的历史样本。

美国总统相关信息拆分为讲话、行政命令、关税、制裁、军事行动、财政立场和对美联储的表态。未经可靠证据支持的个人获利或操纵动机不进入事实字段。

## 防止虚假优秀

- 时间顺序切分，禁止随机打乱训练集和测试集
- 使用滚动/扩展窗口训练
- 宏观数据按首次发布日期对齐，并记录后续修订
- 参数选择只在训练/验证期进行
- 纳入申赎时点、无法成交日期、费用和基金跟踪误差
- 与满仓持有、定投和简单趋势规则同时比较
- 报告年化收益、绝对收益、最大回撤、Calmar、换手率和最差年份
